# 💰 Calculadora de Juros

Este projeto em JavaScript calcula os juros de uma dívida com base nos dias de atraso.

## 🚀 Tecnologias

* JavaScript
* Node.js

## 📥 Como usar

1. Instale as dependências:

```
npm install readline-sync
```

2. Execute o projeto:

```
node app.js
```

## 📊 Funcionalidades

* Entrada de dados pelo usuário
* Cálculo automático de juros
* Exibição do valor total da dívida

## 📌 Regras de juros

* Até 15 dias: 5%
* 16 a 30 dias: 10%
* Acima de 30 dias: 15%
